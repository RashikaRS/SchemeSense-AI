📌 Project Description
SchemeSense is a web application that helps users find suitable Indian government schemes based on their category.

✨ Features
- Student Scheme Recommendation
- Farmer Scheme Recommendation
- Women Welfare Scheme Recommendation
- Startup Scheme Recommendation
- Business Scheme Recommendation
- Senior Citizen Scheme Recommendation
- Direct Apply Button (MyScheme Portal)

 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

🚀 How to Use
1. Enter a category (Student, Farmer, Women, Startup, Business, etc.).
2. Click the Search button.
3. View the recommended government schemes.
4. Click *Apply Now* to visit the official MyScheme portal.

 🌐 Official Website
https://www.myscheme.gov.in
